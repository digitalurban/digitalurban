<a href="http://upload.wikimedia.org/wikipedia/commons/thumb/7/77/BigMacAustralia.jpg/200px-BigMacAustralia.jpg"><img style="margin: 0pt 0pt 10px 10px; float: right; cursor: pointer; width: 186px; height: 139px;" src="http://upload.wikimedia.org/wikipedia/commons/thumb/7/77/BigMacAustralia.jpg/200px-BigMacAustralia.jpg" alt="" border="0" /></a>We have been adding some new maps recently to <a href="http://www.maptube.org/">MapTube</a>, our most recent being the global price of Big Mac's around the world.<br /><br />Based on the Big Mac Index which according to the <a href="http://en.wikipedia.org/wiki/Big_Mac_Index">Wiki</a> was "introduced by <i>The Economist</i> in <span>September 1986</span> as a humorous illustration and has been published by that paper annually since then. The index also gave rise to the word <i>burgernomics</i>. <p>One suggested method of predicting exchange rate movements is that the rate between two currencies should naturally adjust so that a sample basket of goods and services should cost the same in both currencies. In the Big Mac Index, the "<a href="http://en.wikipedia.org/wiki/Basket_%28finance%29" title="Basket (finance)">basket</a>" in question is considered to be a single <a href="http://en.wikipedia.org/wiki/Big_Mac" title="Big Mac">Big Mac</a> burger as sold by the <a href="http://en.wikipedia.org/wiki/McDonald%27s" title="McDonald's">McDonald's</a> fast food restaurant chain.<br /></p><p>The Big Mac was chosen because it is available to a common specification in many countries around the world, with local McDonald's <a href="http://en.wikipedia.org/wiki/Franchising" title="Franchising">franchisees</a> having significant responsibility for negotiating input prices. For these reasons, the index enables a comparison between many countries' currencies. Some menu items are market specific, which would hinder a comparison, if used. Still other menu items are specially priced, such as the dollar menu in many U.S. restaurants consisting of sandwiches and other items that cost $1".</p><p><a href="http://www.maptube.org/map.aspx?s=DCwyokmXTCenc0OMGVwKXBwKgUwKEI"><img style="margin: 0px auto 10px; display: block; text-align: center; cursor: pointer;" src="/assets/uploads/external/1.bp.blogspot.com/_ADwvfqkxChw/SGjxSVBJwkI/AAAAAAAABPE/t-ns9_UvJ6s/s400/Mc.png" alt="" id="BLOGGER_PHOTO_ID_5217685465490637378" border="0" /></a></p><p>Mapping the index provides and instant guide to prices around the world - it makes interesting viewing, China is by far the cheapest place for a BigMac, visualised all thanks to the increasingly easy ways to view and create geotagged information.<br /></p><p>You can <a href="http://www.maptube.org/map.aspx?s=DCwyokmXTCenc0OMGVwKXBwKgUwKEI">View the Map yourself via MapTube</a>, data thanks to  The Economist.<br /></p><p>See the <a href="http://en.wikipedia.org/wiki/Big_Mac_Index">Big Mac Index Wikipedia page</a> for more information.<br /></p>
