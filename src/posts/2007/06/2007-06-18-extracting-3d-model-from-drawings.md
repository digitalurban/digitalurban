Constructing 3D models of buildings is all about extracting the geometry from images using <span>photogrammetric</span> techniques. As such, although it goes against basic geometric principles it also lends itself to historic reconstruction via referenced hand drawn images.<br /><br />Over eight years ago we used the now sadly demised software <a href="http://digitalurban.blogspot.com/2006/12/great-software-from-past-canoma.html"><span>CANOMA</span></a> to create a view of London in 1616 - as the <span>YouTube</span> movie below illustrates:<br /><br /><center><object height="350" width="425"><param name="movie" value="http://www.youtube.com/v/bG6XQGUyvPA"><param name="wmode" value="transparent"><embed src="http://www.youtube.com/v/bG6XQGUyvPA" type="application/x-shockwave-flash" wmode="transparent" height="350" width="425"></embed></object></center><br /><span>CANOMA</span> excelled at such scenes as it required only a single image to define the 3D space compared with many <span>photogrammetric</span> packages which require matching views and overlapping construction points.<br /><br />Using a previous version of <span>SketchUp</span>  - without the <span>PhotoMatch</span> feature - we rediscovered modelling from paper with our take on the Bank of <span>Hong</span> Kong in Google Earth modelled using <a href="http://www.skyscrapermodels.us/Home.html"><span>Skyscrapermodels</span>.us by John Townsend</a> as a resource. The site provides full plans of a number of notable skyscrapers which are designed to be printed out onto card or paper and folded to construct the geometry.<br /><br /><p align="left"><a href="http://photos1.blogger.com/blogger/835/752/1600/Bank_of_China_Tower.jpg"><img style="margin: 0px auto 10px; display: block; cursor: pointer; text-align: center;" alt="" src="/assets/uploads/external/photos1.blogger.com/blogger/835/752/320/Bank_of_China_Tower.jpg" border="0" /></a></p><br />Using <a href="http://www.sketchup.com/"><span>SketchUp</span></a> you can cut and fold digitally to rapidly create a 3D model - see our <a href="http://digitalurban.blogspot.com/2006/08/google-earth-paper-models.html">Google Earth Paper Models post for more details</a>.<br /><br />Taking this further <a href="http://www.sketchup.com/">Google <span>SketchUp</span></a> now has the ability to '<span>PhotoMatch</span>' allowing one to carry out a similar technique to the one used in <span>CANOMA</span>. An example of which can be seen in the model of St Martin's in the Field Church, London, by <a href="http://www.barnabu.co.uk/"><span>barnabu</span></a>:<br /><br /><a href="http://2.bp.blogspot.com/_ADwvfqkxChw/RnZRfhY7YcI/AAAAAAAAAag/fUH7PEdU91g/s1600-h/st-martin-print.thumbnail.jpg"><img style="margin: 0px auto 10px; display: block; text-align: center; cursor: pointer;" src="/assets/uploads/external/2.bp.blogspot.com/_ADwvfqkxChw/RnZRfhY7YcI/AAAAAAAAAag/fUH7PEdU91g/s400/st-martin-print.thumbnail.jpg" alt="" id="BLOGGER_PHOTO_ID_5077335231887532482" border="0" /></a><br />The model is still to be scaled but you can download the model to date directly into <a href="http://www.sketchup.com/">Google <span>SketchUp</span></a> <a href="http://www.barnabu.co.uk/">from <span>barnabu's</span> site</a>.<br /><br />A future project is to reconstruct the Old St Paul's in London  - but as <a href="http://www.sketchup.com/"><span>SketchUp</span></a> is free and easy to use then if you get there first let us know - the <a href="http://images.google.com/imgres?imgurl=http://vrcoll.fa.pitt.edu/medart/image/England/london/Old-Saint-Pauls/London-SSPaul-BondECA-004-b.jpg&imgrefurl=http://vrcoll.fa.pitt.edu/medart/image/England/london/Old-Saint-Pauls/London-OSPaul.html&amp;amp;amp;h=1100&w=1894&amp;sz=1451&hl=en&amp;start=23&um=1&amp;amp;amp;amp;tbnid=Xz8uRy9UP0ZiaM:&tbnh=87&amp;tbnw=150&prev=/images%3Fq%3Dlondon%2Bdrawings%26start%3D21%26ndsp%3D21%26svnum%3D10%26um%3D1%26hl%3Den%26rlz%3D1B2DVFC_enGB213GB213%26sa%3DN">reference image can be found here</a>.
