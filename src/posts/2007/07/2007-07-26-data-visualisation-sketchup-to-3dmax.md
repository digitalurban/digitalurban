Therefore, we thought we would try creating some components in SketchUp and link them to values for population per London Borough for 2006.<br /><img id="BLOGGER_PHOTO_ID_5091535275377074994" style="DISPLAY: block; MARGIN: 0px auto 10px; CURSOR: hand; TEXT-ALIGN: center" alt="" src="/assets/uploads/external/2.bp.blogspot.com/_ADwvfqkxChw/RqjEW1o4ozI/AAAAAAAAAe4/c8zdX4b2sbI/s400/london2.jpg" border="0" /><br />The data input was carried out manually due to errors in installing the new Arc to SketchUp plugin on Vista - thus the use of colours in the model is not linked to the data. Hopefully the plugin will be up and running shortly.<br /><br /><br /><img id="BLOGGER_PHOTO_ID_5091536271809487682" style="DISPLAY: block; MARGIN: 0px auto 10px; CURSOR: hand; TEXT-ALIGN: center" alt="" src="/assets/uploads/external/2.bp.blogspot.com/_ADwvfqkxChw/RqjFQ1o4o0I/AAAAAAAAAfA/kFN_WyrO8IU/s400/londonpop1.jpg" border="0" />Moving from SketchUp to 3DMax allows a 'clay' render to be run on the model giving it a distinctive look.
