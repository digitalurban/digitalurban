<p><a href="http://photos1.blogger.com/blogger2/604/1219/1600/LondonGoogleEarth1.0.jpg"><img style="margin: 0pt 0pt 10px 10px; float: right; cursor: pointer;" src="/assets/uploads/external/photos1.blogger.com/blogger2/604/1219/320/LondonGoogleEarth1.0.jpg" alt="" border="0" /></a>Our<a href="http://digitalurban.blogspot.com/2006/08/google-earth-london-level-of_17.html"> post on progress </a>in the London Google Earth Model last week highlighted the ability to stream in data using the Network capability of KML thanks to Richard Milton at CASA.<br /><br />The movie displayed was created using data direct from <a href="http://www.ordnancesurvey.co.uk/oswebsite/">Ordnance Survey</a> Master Map. This is suitable for general outlines but not for landmark buildings that require higher levels of detail. To import these into Google Earth we have used a combination of <a href="http://www.esri.com/">ESRI's ArcGIS,</a> <a href="http://www.sketchup.com/">SketchUp</a>, <a href="http://geotools.codehaus.org/">GeoTools</a> and good old Notepad. The landmark KMZ's are spliced into the original file structure allowing Network Streaming functionality with the inclusion of landmark buildings.  The latest movie illustrates the Swiss Re and Tower 42 in the wider context of the London model.<br /><br /><object width="414" height="350"><param name="movie" value="http://www.youtube.com/v/ij4Pwg4RqjY"></param><embed src="http://www.youtube.com/v/ij4Pwg4RqjY" type="application/x-shockwave-flash" width="414" height="350"></embed></object><br /><br />All the work flows are in place all we need now is for the parties involved to sort out their data licensing policy...</p>
