The Crysis engine has an inbuilt physics system that supports vehicles, rigid bodies, liquid, rag doll, cloth and soft body effects. The movies in this post provide a glimpse of the physics engine in action, the first clip above demonstrates the 'Lego' modification running in real-time.<br />
The following movies illustrate the use of the physics engine of Crysis in maximum effect. Note each one was rendered frame by frame using the 'linked method', <a href="http://forums.facepunchstudios.com/showthread.php?t=459146">take a look at this thread</a> for full details.<br />
