<span style="font-family: Arial, Helvetica, sans-serif;"><a href="http://www.casa.ucl.ac.uk/people/person.asp?id=28">Richard Milton</a> here in CASA has released a new feature on the <a href="http://www.maptube.org/" style="color: #0066cc; margin-bottom: 0px; margin-left: 0px; margin-right: 0px; margin-top: 0px; outline-color: invert; outline-style: none; padding-bottom: 0px; padding-left: 0px; padding-right: 0px; padding-top: 0px;" target="_blank" title="MapTube" rel="noopener">MapTube</a> website today which will make it easier to create new maps from data in CSV files. The new update to MapTube adds a graphical user interface which allows the user to upload a data file, choose a colour scale and publish the map on MapTube directly. As Richard states, one of the driving forces behind this was the idea that creating a map should be simple enough that you could do it using an iPad. Data on the <a href="http://data.london.gov.uk/" style="color: #0066cc; margin-bottom: 0px; margin-left: 0px; margin-right: 0px; margin-top: 0px; outline-color: invert; outline-style: none; padding-bottom: 0px; padding-left: 0px; padding-right: 0px; padding-top: 0px;" target="_blank" title="London Datastore" rel="noopener">London Datastore </a> is in the correct format, so you can copy the CSV link directly from the site, which is exactly what has been done in the above image. Richard has created a YouTube clip showing the whole process:</span><br /><span style="font-family: Arial, Helvetica, sans-serif;"><br /></span><br /><br /><center><span style="font-family: Arial, Helvetica, sans-serif;"><iframe allowfullscreen="" frameborder="0" height="510" src="http://www.youtube.com/embed/naaSv7ihGOQ?rel=0" width="640"></iframe></span></center><br /><div style="color: #333333; line-height: 20px; margin-bottom: 5px; margin-top: 5px; padding-bottom: 5px; padding-left: 0px; padding-right: 20px; padding-top: 5px;"><span style="font-family: Arial, Helvetica, sans-serif;">This feature is still experimental, but at the moment it handles point data in lat/lon coordinates (WGS84) or OS coordinates for the UK (OSGB36). Point data can be drawn using markers, or as a heatmap showing point density. For area data, one column in the data is selected as a key field and this is joined with the geographic data stored in MapTube’s database to draw the map. For example, using the following data:</span></div><div style="color: #333333; line-height: 20px; margin-bottom: 5px; margin-top: 5px; padding-bottom: 5px; padding-left: 0px; padding-right: 20px; padding-top: 5px;"><a href="http://genesis.blogs.casa.ucl.ac.uk/files/2011/08/electiondatamay2010.jpg" style="color: #0066cc; margin-bottom: 0px; margin-left: 0px; margin-right: 0px; margin-top: 0px; outline-color: invert; outline-style: none; padding-bottom: 0px; padding-left: 0px; padding-right: 0px; padding-top: 0px;"><span style="font-family: Arial, Helvetica, sans-serif;"><img alt="" class="alignnone size-medium wp-image-223" height="142" src="/assets/uploads/external/genesis.blogs.casa.ucl.ac.uk/files/2011/08/electiondatamay2010-300x142.jpg" style="border-bottom-width: 0px; border-color: initial; border-left-width: 0px; border-right-width: 0px; border-style: initial; border-top-width: 0px; margin-bottom: 0px; margin-left: 0px; margin-right: 0px; margin-top: 0px; padding-bottom: 0px; padding-left: 0px; padding-right: 0px; padding-top: 0px;" width="300" /></span></a></div><div style="color: #333333; line-height: 20px; margin-bottom: 5px; margin-top: 5px; padding-bottom: 5px; padding-left: 0px; padding-right: 20px; padding-top: 5px;"><span style="font-family: Arial, Helvetica, sans-serif;">We have four columns: Constituency, Party, PartyCode and Change. In the CSV file the first line must be the column headings, then every subsequent line contains data. The CSV file would contain the following:</span></div><pre style="color: #333333; line-height: 20px; padding-bottom: 0px; padding-left: 0px; padding-right: 0px; padding-top: 0px;"><span style="font-family: Arial, Helvetica, sans-serif;">Constituency,Party,PartyCode,Change<br />Aberavon,LAB,1,LAB Hold<br />Aberconwy,CON,2,CON Gain<br />etc...<br /></span></pre><div style="color: #333333; line-height: 20px; margin-bottom: 5px; margin-top: 5px; padding-bottom: 5px; padding-left: 0px; padding-right: 20px; padding-top: 5px;"><span style="font-family: Arial, Helvetica, sans-serif;">The “Constituency” column is the area key in this case, but MapTube determines this automatically when the CSV file is loaded, along with the type of geography, which is Parliamentary Constituencies. In order to colour the map, numeric data is required, so in this example, a column labelled “PartyCode” has been added where “LAB”=1, “”CON”=2, LD=”3″ etc.</span></div><div style="color: #333333; line-height: 20px; margin-bottom: 5px; margin-top: 5px; padding-bottom: 5px; padding-left: 0px; padding-right: 20px; padding-top: 5px;"><span style="font-family: Arial, Helvetica, sans-serif;">The colour scale is then chosen and the finished map submitted to MapTube where it can be viewed along with any of the other maps. There are help pages accessible through the ‘i’ icon on each section which contain further information.</span></div><div style="color: #333333; line-height: 20px; margin-bottom: 5px; margin-top: 5px; padding-bottom: 5px; padding-left: 0px; padding-right: 20px; padding-top: 5px;"><span style="font-family: Arial, Helvetica, sans-serif;">As mentioned before, this feature is still experimental and we will be gradually adding more geographic data to the MapTube database to allow maps to be built from additional geographies.
