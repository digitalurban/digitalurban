<p><a href="http://photos1.blogger.com/blogger/835/752/1600/minority-report.0.jpg"><img style="FLOAT: right; MARGIN: 0px 0px 10px 10px; CURSOR: hand" alt="" src="/assets/uploads/external/photos1.blogger.com/blogger/835/752/320/minority-report.0.jpg" border="0" /></a><a href="http://photos1.blogger.com/blogger/835/752/1600/atlasgloves_diy181.jpg"><img style="FLOAT: left; MARGIN: 0px 10px 10px 0px; CURSOR: hand" alt="" src="/assets/uploads/external/photos1.blogger.com/blogger/835/752/200/atlasgloves_diy181.jpg" border="0" /></a><br />Picked up via the ever impressive <a href="http://www.ogleearth.com/">Oogle Earth Blog </a>is the news that Atlas Gloves was <a href="http://phiffer.org/">Dan Phiffer</a> and <a href="http://shual.com/">Mushon Zer-Aviv</a> part of the<a href="http://itp.nyu.edu/itp/flash/Home"> ITP - NYU’s Interactive </a><a href="http://itp.nyu.edu/itp/flash/Home">Telecommunication Program</a>. have developed a pair of 'Atlas Gloves'. The gloves are a DIY physical interface for controlling 3D mapping applications like <a href="http://earth.google.com/">Google Earth</a>. The user interface is based around a pair of illuminating gloves that can be used to track intuitive hand gestures like grabbing, pulling, reaching and rotating. The <a href="http://atlasgloves.org/">Atlas Glove website </a>has a video of the interface in action as well as details on how to build you own from a pair of ping pong balls, led lights and a webcam.<br /><br />We are on the case and people are being dispatched to locate ping pong balls as we type. If we get it up and running we will put up a post as well as contacting the team to see if we can help out in any way with other applications such as ArcExplorer (?)....<br /><br />****<br />As an update we have our ping pong balls (thanks Joel), super glue and a couple of cheap led torches. If we dont glue our fingers together we should be running a test this afternoon and updates will follow on our progress. (2nd August 2006).<br /><br />****</p>
