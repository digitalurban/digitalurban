<p>In 2008 Google announced the Earth API and Google Earth Plugin tandem as a pioneering new avenue for 3D content delivery on the web. The API made it possible for developers to create high performance, rich, geospatial web applications purely in JavaScript and HTML. In the movie below Roman discuss advanced Earth API topics such as programmatic regionation for visualizing large datasets, user interaction techniques, and 3D animation.
