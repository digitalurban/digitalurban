<p><a href="http://1.bp.blogspot.com/_ADwvfqkxChw/SeMLBH6PK_I/AAAAAAAACFg/YsSMU5hFO1Y/s1600-h/editor-broad.jpg"><img style="margin: 0px auto 10px; display: block; text-align: center; cursor: pointer; width: 400px; height: 203px;" src="/assets/uploads/external/1.bp.blogspot.com/_ADwvfqkxChw/SeMLBH6PK_I/AAAAAAAACFg/YsSMU5hFO1Y/s400/editor-broad.jpg" alt="" id="BLOGGER_PHOTO_ID_5324111298413145074" border="0" /></a><a href="http://en.wikipedia.org/wiki/Unity_%28game_engine%29"><span>Wikipedia</span></a> describes Unity  as an integrated authoring tool for creating 3D video games or other interactive content such as architectural visualizations or real-time 3D animations. Unity is similar to <a href="http://en.wikipedia.org/wiki/Macromedia_Director" title="Macromedia Director">Director</a>, <a href="http://en.wikipedia.org/wiki/Game_Blender" title="Game Blender">Blender game engine</a>, <a href="http://en.wikipedia.org/wiki/Virtools" title="Virtools"><span>Virtools</span></a> or <a href="http://en.wikipedia.org/wiki/Torque_Game_Builder" title="Torque Game Builder">Torque Game Builder</a> in the sense that an integrated graphical environment is the primary way of authoring the game.<br /><br />The editor runs on Windows and Mac OS X and can produce games for Windows, <span>Mac</span>, <span>Wii</span><sup><span></span><span></span></sup>, or iPhone<sup><span> </span><span></span></sup>platforms. It can also produce browser games that use the Unity web player <span>plugin</span>, supported on <span>Mac</span> and Windows.<br /><br />The movie below by <a href="http://www.youtube.com/user/3dnemo" onmousedown="urchinTracker('/Events/VideoWatch/ChannelNameLink');">3<span>dnemo</span></a> provides an insight into the possibilities:<br /><center><object height="385" width="480"><param name="movie" value="http://www.youtube.com/v/kxdQQ0MS8WQ&hl=en&fs=1"><param name="allowFullScreen" value="true"><param name="allowscriptaccess" value="always"><embed src="http://www.youtube.com/v/kxdQQ0MS8WQ&hl=en&fs=1" type="application/x-shockwave-flash" allowscriptaccess="always" allowfullscreen="true" height="385" width="480"></embed></object></center><br /><br />Version 2.5 now supports the ability to drag and drop .max files right into the Editor, including support for all skeletal based animation, multiple <span>UVs</span>, and vertex colors. This builds on the existing support for Maya, Blender, and all other 3D applications that integrate with the latest <span>FBX</span> <span>plugin</span> on the Windows platform.<br /><br />There are two main licenses: Unity Indie ($199), and Unity Pro ($1499)<span style="text-decoration: underline;">.</span><sup><a href="http://en.wikipedia.org/wiki/Unity_%28game_engine%29#cite_note-licensing-16" title=""><span></span></a></sup> The Pro version has additional features like render-to-texture, <span>postprocessing</span> effects, and the ability to build standalone Windows games. Unity Pro is also required for businesses with over $100,000 turnover/year.<br /><br />The second movie, again by <a href="http://www.youtube.com/user/3dnemo" onmousedown="urchinTracker('/Events/VideoWatch/ChannelNameLink');">3<span>dnemo</span></a> , illustrates a cityscape running within Unity:<br /><br /><center><object height="385" width="480"><param name="movie" value="http://www.youtube.com/v/xBXdNKUQCb0&hl=en&fs=1"><param name="allowFullScreen" value="true"><param name="allowscriptaccess" value="always"><embed src="http://www.youtube.com/v/xBXdNKUQCb0&hl=en&fs=1" type="application/x-shockwave-flash" allowscriptaccess="always" allowfullscreen="true" height="385" width="480"></embed></object></center><br /><br />We will be taking a closer look at Unity over the coming weeks, for now see <a href="http://unity3d.com/unity/">http://unity3d.com/unity/</a> for more information.<br /><br />Thanks go to an anonymous commenter in our post on <a href="http://digitalurban.blogspot.com/2009/04/hypershot-near-realtime-rendering.html"><span>hyperShot</span>: Near <span>Realtime</span> Rendering System for Windows and Mac</a> for mentioning Unity...<br /><br />Update - <a href="http://digitalurban.blogspot.com/2009/05/unity-city-data-and-simulation.html">See our Sample City Exhibition Space in Unity for Windows and Mac</a>.<br /><h3> </h3>    <a href="http://4.bp.blogspot.com/_ADwvfqkxChw/SdyxZymOPUI/AAAAAAAACEw/mqNfnSlTSlE/s1600-h/header-hypershot.png"><br /><br /><br /></a></p>
