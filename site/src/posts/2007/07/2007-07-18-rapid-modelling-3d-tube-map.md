<p><center><img src="/assets/uploads/external/www.casa.ucl.ac.uk/andy/blogimages/tube1.jpg" /></center><br /><br />Rapid visualisation of networks can be carried out by simply converting Adobe Acrobat documents to .dwg format as we detail below with a quick render of the London Tube map:<br /><br />Modelling of the tube lines was possible using the following workflow:<br /><br />1) Download a Acrobat formatted 2D map from the <a href="http://www.tfl.gov.uk/">London Transport</a> site;<br /><br />2) Import into Adobe Illustrator;<br /><br />3) Export as .DWG which preserves the vector line data;<br /><br />4) Import into 3DMax and converting the line data into 3D Splines.<br /><br />This provides a quick and easy way to transform a 2D map into 3D.
