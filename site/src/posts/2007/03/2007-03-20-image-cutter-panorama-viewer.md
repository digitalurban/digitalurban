<p>Neil Creek has used our labs (<a href="http://www.casa.ucl.ac.uk/"><span>CASA</span></a>) Image Cutter software to view a stunning panorama online, as the live example below demonstrates (you can close the preview window by clicking on the bottom right hand arrow, navigate using the standard Google Map interface):<br /><br /><iframe align="center" src="http://neil.creek.name/panoramas/fortyfivemp_creek-061116-217-pano.html" frameborder="0" width="495" scrolling="no" height="300"></iframe><br /><br />The software is aimed at easy viewing of <span>giga</span> pixel images over the web without the need of a <span>plugin</span>. Using the Google Maps interface it 'cuts' up the image into thousands of sections and then creates a web template which can be modified for own usage or <span>embedded</span> into a blog etc.<br /><br />Take a look at <a href="http://neil.creek.name/panoramas/">Neil's site</a> for more panoramas and thanks for the comments on the software so far Neil. If you would like to try it yourself,<a href="http://www.casa.ucl.ac.uk/software/googlemapimagecutter.asp">download version 1.1</a></p>
